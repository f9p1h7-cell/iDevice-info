# Apple Watch Jailbreaks
 
No public, mainstream jailbreak currently exists for any watchOS version — the dev community is far smaller than iOS and tethered research tools have surfaced but nothing public/stable
 
# MacBook Jailbreaks
 
Not applicable in the traditional jailbreak sense — macOS already allows installing apps and code outside the Mac App Store (Gatekeeper can be adjusted in Settings), so there's no lock to break the way there is on iOS/iPadOS/watchOS
